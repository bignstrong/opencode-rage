# Russian wake detector

`Detector::push` consumes exactly 160 signed 16-bit mono samples at 16 kHz (10 ms). It returns one `true` per match, then suppresses repeat events for 800 ms. `reset()` clears audio history, scores and cooldown. An incorrectly sized frame clears history and returns `false`. There is no text recognition, network access or per-frame heap allocation.

## Personal calibration

Set `RAGE_WAKE_PROFILE` to a private local directory to use your own templates in place of the built-ins. Keep 3–8 `.wav` files in it. At least three must be positive examples. A file starting with `reject-` is a negative example; other WAVs are positive. File names do not need to contain the word.

- Use distinct examples of «Рейдж» from the same speaker, at normal speaking volume and different speeds. Include a few examples cut out of naturally spoken commands: keep the entire wake word, ending immediately before the next word.
- To reduce confusion, include `reject-reis.wav` («рейс») and `reject-rech.wav` («речь»). The eight-file limit includes these negatives. Positive-only enrollment is supported but produced more false triggers in testing.
- Use regular, mono PCM16 WAV files, 8–96 kHz, up to 4 seconds and 800,000 bytes per file. Leading/trailing quiet is trimmed; the active portion must be 150–1500 ms. Symlinks, unreadable files, malformed WAVs and invalid profiles fail startup. No files in the directory are created or changed.

For example, launch the usual host with `RAGE_WAKE_PROFILE="$HOME/.rage/wake-examples"` in its environment. The native caller loads the directory once using `Detector::from_wav_dir(&Path) -> Result<Self, String>` before opening audio. Unset the variable to restore `Detector::new()`. There is no automatic recording or enrollment. Speaker-specific templates are not speaker authentication.

## Built-in templates

`milena.bank` contains **10,671 bytes** of quantized spectral features, not waveform recordings. `rust/qa/wake-corpus.py train` regenerates it from the macOS Russian Milena voice. The detector computes a Hann-windowed 256-point FFT, maps power into 16 bands, and uses streaming subsequence dynamic time warping. The built-in bank contains three positive pronunciations and two confusables at three pitch scales. A personal profile instead scores the supplied examples and requires agreement between two positive takes. With negative examples, the detector also compares their scores within ±60 ms.

## Offline measurements

All results below are from synthetic speech. They do not measure human recall or room false alarms per hour.

| Built-in detector, continuous Milena stream | Positives detected | False events | Negative clips (including simulated background) |
| --- | ---: | ---: | ---: |
| Development | 63/63 | 0 | 231 |
| Earlier held-out set, rerun after pitch augmentation | 39/40 | 0 | 139 |
| Fresh phrases and pitch/gain/noise combinations | 51/51 | 3 | 123 |

The fresh set failed the zero-false-event gate: «эй Джон» twice, «рейтинг вырос» once. Its 401.1 s PCM stream took 0.156 s in the standalone optimized driver on the development Mac, including process startup and reading the PCM file. The median trigger on first-word positives was 407 ms from utterance start; this is not a word-end timing measurement.

**Different Russian voice:** a 172.3-second continuous stream generated by Piper `ru_RU-denis-medium` contained 18 positives, 36 negative speech clips and 30 seconds of simulated background. The training words and the two manually cut training phrases were not taken from the test stream. Only events 100–1200 ms after the start of a positive utterance counted as hits.

| Detector / enrollment | Positives detected | False or extra events |
| --- | ---: | ---: |
| Built-in Milena bank | 0/18 | 0 |
| Six Denis positives (four isolated, two cut from natural phrases) | 15/18 | 9 |
| Same six plus «рейс» and «речь» negatives | 15/18 | 6 |
| Actual Rustpotter 3.0.2, default configuration, 16 MFCCs, same six trimmed positive WAVs | 18/18 | 28 |

Personal calibration helped the second voice, but all three rates of «Рейдж прочти письмо» were missed. «Речь идёт о дороге» and «этот рейс задержали» each triggered at all three rates even with contrasts. Rustpotter numbers describe its defaults, not its best achievable tuning. None of these configurations established reliable speaker-independent detection.

## Reproduce

From the repository root, run `python3 rust/qa/wake-corpus.py` with `validate`, `dev`, `held-out`, `fresh` or `voices`. The `fresh` gate currently exits 1. `validate` checks a valid profile and eight invalid inputs. `train` explicitly regenerates the tracked bank; the other commands keep generated audio and executables under ignored `native/target/wake-corpus/`.

With Piper and a Russian model already available locally:

```sh
python rust/qa/wake-corpus-profile.py /path/to/ru_RU-denis-medium.onnx --split test
```

To repeat the Rustpotter comparison, build its driver separately. Neither dependency is used by the shipped detector. From the repository root:

```sh
work=$(mktemp -d)
cargo new --quiet --bin "$work/comparator"
cp rust/qa/wake-corpus-rustpotter.rs "$work/comparator/src/main.rs"
cargo add --manifest-path "$work/comparator/Cargo.toml" 'rustpotter@=3.0.2' 'half@=2.3.1'
cargo build --release --manifest-path "$work/comparator/Cargo.toml"
uv run --python 3.11 --with piper-tts python rust/qa/wake-corpus-profile.py \
  /path/to/ru_RU-denis-medium.onnx --split test --candidate "$work/comparator/target/release/comparator"
```
