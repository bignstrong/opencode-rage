# Distribution

Rage is distributed through [GitHub Releases](https://github.com/bignstrong/opencode-rage/releases). On Apple Silicon, run `npm ci`, `npm run build:native`, then `npm pack`. Publish the tarball as `opencode-rage-v<VERSION>-darwin-arm64.tgz` with its `SHA256SUMS`. Follow the [install instructions](README.md) to test the extracted package. This does not publish to npm or release a speech model or engine.
