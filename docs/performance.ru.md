# Диктовка на M2 Max: что влияет на задержку

Измерения на Apple Silicon, macOS 27.2.1. Вход: 5,37 секунды синтезированной русской речи, PCM16, моно, 16 кГц. Движок, файлы моделей и вход одинаковы для обеих версий плагина; запись с микрофона не используется.

| Модель | Исходный `VoiceRuntime`, медиана | `VoiceRuntime` с Rust, медиана |
| --- | ---: | ---: |
| Whisper large-v3-turbo | 1136 мс | 1188 мс |
| Whisper large-v3-turbo Q5_0 | 860 мс | 868 мс |

Каждая ячейка — четыре запуска публичного `transcribe()` в новом процессе, очистка звука отключена. Порядок версий чередуется. Распознанный текст совпал. Измерение включает запуск движка и загрузку модели, исключает старт Node и захват звука. Небольшая выборка не позволяет оценить p95 или качество распознавания живой речи.

**Практический выбор:** для короткой диктовки на этом Mac сначала попробуй `whisper-turbo-q5_0`. Основной выигрыш здесь дала модель, а не переписывание обвязки. В отдельном тесте `whisper-cli` Turbo Q5_0 обработала тот же вход за 856 мс против 1525 мс у large-v3 Q5_0 (медиана трёх запусков). Движок обеих версий использовал Metal.

Повторить без сети с уже установленными моделями и синтетическим WAV:

```sh
npm run build:native
node rust/qa/compare-inference.mjs input.wav whisper-turbo
node rust/qa/compare-inference.mjs input.wav whisper-turbo-q5_0
```

Публичные интерфейсы: [whisper.cpp на Apple Silicon](https://github.com/ggml-org/whisper.cpp), [плагины терминала OpenCode](https://opencode.ai/docs/build/plugins/cli).
