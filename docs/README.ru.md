# Setup OpenCode на macOS

Плагин добавляет в OpenCode V2 кнопки записи и отправки, темы, думающий орб и диктовку. На macOS записью и локальным распознаванием управляет ядро на Rust, а адаптер на TypeScript подключает команды и поле ввода OpenCode.

Под полем ввода справа две кнопки: `↑` отправляет черновик, `●` начинает запись. Если начали запись кликом по `●`, нажмите `Enter` в поле ввода или кликните по `■`, чтобы закончить диктовку. Текст появится у курсора. Можно допечатать или надиктовать ещё. Нажмите `↑`, чтобы отправить черновик вместе с вложениями. После остановки через `Enter` второе нажатие отправит черновик только в терминале, который отличает новое нажатие от автоповтора. `Ctrl+P` открывает команды.

Если случайно стёрли диктовку, нажмите `Ctrl+P` и выберите **Вставить последнюю диктовку**. Последний вставленный фрагмент вернётся к курсору один раз в исходном чате или рабочей области. Черновик останется в поле ввода.

Если во время распознавания вы открыли другой чат, вернитесь в исходный черновик. Диктовка дождётся его в памяти до закрытия терминала или перезагрузки плагина.

При первом включении Rage устанавливает встроенную тему OpenCode `orng`. Светлый или тёмный режим сохраняется. Тему можно поменять позже: Rage не будет возвращать её при каждом запуске.

Во время записи видны волна и длительность. При распознавании речи появляется оранжевый цифровой дождь. Пока агент думает, по умолчанию виден оранжевый «Цифровой вдох». Анимацию агента можно поменять через `/orbs`, а движение отключить в `/voice-settings` → **Запись**. Горячей клавиши по умолчанию нет: `Ctrl+Space` остаётся у macOS.

Язык меню и распознавания по умолчанию русский. Чтобы сменить язык меню, откройте `/voice-settings` → **Язык интерфейса** и выберите **Русский** или **English**. Язык распознавания настраивается отдельно.

## Установить готовый релиз

На Mac с Apple Silicon скачайте архив и `SHA256SUMS` со [страницы v0.2.0](https://github.com/bignstrong/opencode-rage/releases/tag/v0.2.0). В каталоге загрузки выполните:

```sh
shasum -a 256 -c SHA256SUMS
mkdir -p "$HOME/.local/share/rage/0.2.0"
tar -xzf opencode-rage-v0.2.0-darwin-arm64.tgz -C "$HOME/.local/share/rage/0.2.0"
cd "$HOME/.local/share/rage/0.2.0/package"
npm install --omit=dev
pwd
```

Добавьте путь из `pwd` в массив `plugins` файла `~/.config/opencode/cli.json`. В открытом OpenCode выполните `/reload`. Собирать Rust и отдельно настраивать тему не нужно.

## Подключить локальную копию в OpenCode V2

**Переход с `opencode-voice` на macOS.** Закройте OpenCode до первого запуска Rage. После `npm run build:native` выполните из каталога Rage:

```sh
./native/target/release/rage-core migrate-settings "${XDG_STATE_HOME:-$HOME/.local/state}/opencode/latest/tui"
```

Это путь для канала `latest` в OpenCode 2.4.1. Для другого профиля посмотрите `state` в выводе `opencode debug paths` и укажите абсолютный путь без симлинков к каталогу с `plugin.opencode-voice.settings.json`. Команда создаст `plugin.rage.settings.json` с правами только для владельца. Старый файл останется на месте. Если настроек старого плагина нет или файл Rage уже существует, ничего не изменится. Команда выводит только результат. Модели и движки останутся в прежнем кеше. Затем замените старую запись в `plugins` и запустите OpenCode.

Если Rust-версия уже собрана, перейдите в её каталог и запустите OpenCode для разовой проверки:

```sh
OPENCODE_CLI_CONFIG_CONTENT="$(node -p 'JSON.stringify({plugins:[process.cwd()]})')" opencode
```

Для постоянного подключения или новой копии:

1. Из корня репозитория выполните `npm ci`, затем `npm run build:native`. Для сборки нужны Cargo и Xcode Command Line Tools. Проверка без записи: `./bin/setup-opencode doctor`. На macOS команда запускает Rust без Node. Если установить зависимости с `--ignore-scripts`, npm не скачает встроенный FFmpeg: понадобится установленный FFmpeg с AVFoundation или SoX для системного входа.
2. В `~/.config/opencode/cli.json` добавьте **абсолютный путь к каталогу** в существующий массив `plugins`. Если там уже есть опубликованная версия плагина, замените её локальной. Вместо `/absolute/path/rage` подставьте вывод `pwd` из корня репозитория:

   ```json
   {
      "plugins": ["/absolute/path/rage"]
   }
   ```

3. Запустите `opencode` из каталога своего проекта. На чистой установке уже выбрана `whisper-turbo`, автоотправка выключена. Модель не скачивается при запуске OpenCode. Если плагином уже пользовались, сохранённые настройки имеют приоритет.
4. Разрешите терминалу доступ к микрофону в системных настройках macOS. Если захватывается не тот вход, выберите микрофон в `/voice-settings`.

Откройте `/voice-settings` → **Микрофон**. В V2 список обновляется, пока меню открыто: подключите USB-микрофон, AirPods или iPhone, доступный в macOS через Continuity. Чтобы диктовать через телефон, выберите его по имени, включите запись на Mac и говорите в iPhone.

**Системный микрофон** берёт вход из **Системные настройки → Звук → Вход** для каждой новой записи. Если выбрать устройство по имени, плагин запомнит его. Подключение другого микрофона не переключает текущую запись. Если активный микрофон отключится, плагин распознает доступную часть записи, оставит текст в черновике и предложит выбрать вход для следующей записи. Черновик не отправляется автоматически.

Старые версии FFmpeg показывают только имя устройства. Если плагин не может различить два одноимённых микрофона, отключите второй перед записью.

**Проверка на своём iPhone.** Выключите автоотправку. Откройте список микрофонов на Mac и подключите iPhone: его имя должно появиться без повторного открытия списка. Выберите iPhone, нажмите `●` на Mac, произнесите короткую фразу и нажмите `■`. Фраза должна появиться в редактируемом черновике. Во второй записи отключите iPhone после нескольких слов: уже записанная речь должна остаться в черновике, а Rage должен предложить выбрать другой вход. Если запись не начинается, сначала проверьте, виден ли iPhone в **Звук → Вход** и выдан ли терминалу доступ в **Конфиденциальность и безопасность → Микрофон**.

При начале загрузки появится одно уведомление с названием модели и подсказкой, где смотреть прогресс. Под полем ввода появится `Загрузка модели 73%`. Если размер неизвестен, вместо процентов виден скачанный объём. При паузе сети подсказка остаётся на месте. Можно продолжать печатать: повторный выбор той же модели не запустит вторую загрузку. После проверки SHA256 появится `Диктовка готова` на три секунды или до начала записи. При сбое подсказка останется. Название модели, объём или причину ошибки можно посмотреть в `/voice-settings` → **Распознавание**.

## Что делают команды

**Без кнопки, по имени.** В `/voice-settings` выберите конкретный микрофон и заранее скачайте модель. Откройте нужный чат, включите `/rage-listen` и обычным темпом скажите «Рейдж открой настройки». Не ждите индикатора после имени. Он показывает, что Rage услышал обращение; после паузы в черновике должно появиться «Открой настройки». Настройки сами не откроются. Даже при включённой автоотправке решение об отправке остаётся за вами.

Пауза в 800 мс завершает команду; предельная длина записи команды — 20 секунд. Следующее обращение произносите, когда снова видно `Жду «Рейдж»`. Во время распознавания предыдущей команды новые обращения не накапливаются.

Рядом с `Жду «Рейдж»` отображается уровень входа. `Тихо` означает низкий уровень, `Есть звук` означает, что с выбранного микрофона поступает слышимый сигнал. Шкала реагирует и на обычный звук: имя для её проверки произносить не нужно. Если шкала реагирует, но надпись не меняется на `Слышу «Рейдж»`, детектор не распознал имя. Чтобы перейти к ручной диктовке, выключите `/rage-listen` и нажмите `●`.

Повторный `/rage-listen` выключает ожидание и освобождает вход. Если в поле уже есть текст, ту же команду можно выбрать через `Ctrl+P`. При закрытии TUI этот режим останавливается.


**Чтобы говорить и сразу отправлять**, выключите `/rage-listen`, если он включён, и выберите `/rage-auto` в нужном чате. Например, «Рейдж проверь тесты» отправится после окончания фразы и расшифровки. Если OpenCode ещё отвечает, следующая фраза дождётся своей очереди. Смена чата или повторный `/rage-auto` отменяет ещё не отправленные фразы. Если в поле уже был черновик, результат добавится к нему без отправки.

Режим экспериментальный: в тестах встречались и пропуски имени, и ложные срабатывания на похожих словах. [Измерения и сравнение детекторов](performance.ru.md#почему-режим-экспериментальный).

**Если «Рейдж» пропускается.** Встроенные образцы не универсальны. Подготовьте отдельную папку с 3–8 короткими WAV своего голоса (PCM16, моно). Произнесите имя в разном темпе; пару примеров лучше вырезать из слитной фразы до начала команды. Можно добавить «рейс» и «речь» под именами `reject-1.wav`, `reject-2.wav`: максимум восемь файлов всего, среди них минимум три с именем «Рейдж». Запустите OpenCode с `RAGE_WAKE_PROFILE="$HOME/rage-examples"` в окружении. Rage читает эти файлы только при включении режима. Для проверки используйте другие фразы, а не сами образцы.

В локальном тестовом запуске Mac откройте `Rage — калибровка.command`. После четырёх образцов введите `фразы`. Скажите каждую подсказку без паузы; мастер проиграет короткий фрагмент уже после выключения микрофона. Если начало команды слышно, нажмите `-`; если конец имени обрезан, нажмите `+`. Подтвердите Enter, когда слышно ровно «Рейдж». Затем мастер отдельно проверит имя, две новые команды, слова «рейс» и «речь» в предложениях и тишину. При неудаче тестовый профиль не активируется. В `~/Library/Application Support/Rage Check/profiles/pending` останутся учебные образцы для повторной попытки; `last-check.json` рядом содержит результаты без звука.

**Проверка своим голосом и через Continuity.** Скажите фразу слитно пять раз, меняя темп. Сосчитайте пропуски и проверьте, что каждый раз сохранилось первое слово «открой». Затем скажите «рейс», «речь» и несколько фраз без обращения: черновик не должен измениться. Для проверки iPhone выберите его **по имени**, начните команду и отключите телефон до паузы. Ожидание должно прекратиться, незаконченный текст не должен появиться. Скажите ещё одну команду рядом с Mac: встроенный микрофон не должен подхватить её. Верните iPhone и явно включите режим снова.

**Словарь диктовки.** Добавьте `"dictationDictionary": {"кубер контрол": "kubectl"}` в `options` плагина в `cli.json`. Словарь ищет целые слова без учёта регистра. Если с одной позиции подходят две фразы, побеждает длинная. Меняется только новый фрагмент ручной диктовки при вставке в черновик OpenCode V2.

**Записи для обучения.** По умолчанию плагин не собирает датасет. Для сбора укажите абсолютный путь к личной папке (права `700`) в `RAGE_TRAINING_DIR` или в `options.trainingDir` плагина. Отдельному мастеру калибровки нужен `RAGE_TRAINING_DIR` в окружении, чтобы добавлять записи в эту папку. `RAGE_SAVE_TAKES=0` приостанавливает сбор. Rage сохраняет завершённые команды, ручную диктовку и дубли калибровки. Фоновое ожидание и отменённые до завершения записи туда не попадают. Аудио и исходная расшифровка до замен словаря хранятся на Mac. Для обучения нужен отдельно подтверждённый текст.

В персональном запуске `Rage — проверка.command` режимы **1** и **3** сохраняют записи в `~/Library/Application Support/Rage Check/training`. Режим **4** позволяет прослушать и исправить текст. Демо ничего не добавляет. Для запуска без сбора используйте `RAGE_SAVE_TAKES=0 "$HOME/Desktop/Rage — проверка.command" 1`. Из каталога исходников команда `python3 scripts/training_data.py manifest "$HOME/Library/Application Support/Rage Check/training"` выведет только размеченные примеры; она не обучает модель и не отправляет файлы.

В `/voice-settings` → **Распознавание** → **Модель** сначала показаны **Скачанные модели** из текущей папки загрузок. Выберите нужную, чтобы переключиться без повторной загрузки. Файлы, которым нужна проверка, показаны отдельно.

| Команда | Результат |
| --- | --- |
| `/voice` | Начинает и останавливает запись. По умолчанию вставляет текст в черновик. |
| `/rage-listen` | Включает или выключает ожидание слова «Рейдж». Вставляет только команду, без отправки. |
| `/rage-auto` | Включает голосовую отправку в текущем чате. После паузы отправляет готовую расшифровку. Если вы уже начали писать, добавляет диктовку в черновик и оставляет отправку вам. Повторная команда выключает режим. |
| `/voice-submit` | Отправляет сразу, если исходный чат всё ещё открыт. В остальных случаях оставляет текст в исходном поле ввода. |
| `/voice-stop` | Отменяет запись или распознавание. |
| `/voice-settings` | Выбор языка, модели, микрофона, клавиши, фильтра и автоотправки. |

Распознавание начинается **после** остановки. Whisper использует `whisper-cli`, модели Handy в формате GGUF (включая GigaAM для русского) используют `opencode-voice-transcribe`. Аудио обрабатывается локально. Отправленный текст становится обычным сообщением OpenCode; куда он уйдёт дальше, зависит от настроенного провайдера.

Для сравнения моделей запишите одну и ту же рабочую фразу с именами классов, путями и англоязычными терминами. Сравните ошибки в этих именах и время до результата. Выбор лучшей модели зависит от микрофона, железа и речи.
