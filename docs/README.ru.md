# Rage для OpenCode на macOS

Под полем ввода справа две кнопки: `↑` отправляет черновик, `●` начинает запись. Продиктуйте текст и нажмите `■`: текст появится у курсора. Можно допечатать или надиктовать ещё. Чтобы отправить черновик вместе с вложениями, нажмите `↑` или `Enter`. `Ctrl+P` по-прежнему открывает команды.

Если во время распознавания вы открыли другой чат, вернитесь в исходный черновик. Диктовка дождётся его в памяти до закрытия терминала или перезагрузки плагина.

При первом включении Rage устанавливает встроенную тему OpenCode `orng`. Светлый или тёмный режим сохраняется. Тему можно поменять позже: Rage не будет возвращать её при каждом запуске.

Во время записи кнопка показывает волну и длительность. Пока агент думает, виден оранжевый «Цифровой вдох». В `/orbs` можно выбрать «Цифровой дождь» или «Вдох и дождь». Enter сохраняет выбор, Esc оставляет текущий. Движение можно отключить в `/voice-settings` → **Запись**. Горячей клавиши по умолчанию нет: `Ctrl+Space` остаётся у macOS.

Язык меню и распознавания по умолчанию русский. Чтобы сменить язык меню, откройте `/voice-settings` → **Язык интерфейса** и выберите **Русский** или **English**. Язык распознавания настраивается отдельно.

## Установить готовый релиз

На Mac с Apple Silicon скачайте архив и `SHA256SUMS` со [страницы v0.2.0](https://github.com/bignstrong/opencode-rage/releases/tag/v0.2.0). В каталоге загрузки выполните:

```sh
shasum -a 256 -c SHA256SUMS
mkdir -p "$HOME/.local/share/rage/0.2.0"
tar -xzf opencode-rage-v0.2.0-darwin-arm64.tgz -C "$HOME/.local/share/rage/0.2.0"
cd "$HOME/.local/share/rage/0.2.0/package"
npm install --omit=dev
pwd
```

Добавьте путь из `pwd` в массив `plugins` файла `~/.config/opencode/cli.json`. В открытом OpenCode выполните `/reload`. Собирать Rust и отдельно настраивать тему не нужно.

## Подключить локальную копию в OpenCode V2

**Переход с `opencode-voice` на macOS.** Закройте OpenCode до первого запуска Rage. После `npm run build:native` выполните из каталога Rage:

```sh
./native/target/release/rage-core migrate-settings "${XDG_STATE_HOME:-$HOME/.local/state}/opencode/latest/tui"
```

Это путь для канала `latest` в OpenCode 2.4.1. Для другого профиля посмотрите `state` в выводе `opencode debug paths` и укажите абсолютный путь без симлинков к каталогу с `plugin.opencode-voice.settings.json`. Команда создаст `plugin.rage.settings.json` с правами только для владельца. Старый файл останется на месте. Если настроек старого плагина нет или файл Rage уже существует, ничего не изменится. Команда выводит только результат. Модели и движки останутся в прежнем кеше. Затем замените старую запись в `plugins` и запустите OpenCode.

Если Rust-версия уже собрана, перейдите в её каталог и запустите OpenCode для разовой проверки:

```sh
OPENCODE_CLI_CONFIG_CONTENT="$(node -p 'JSON.stringify({plugins:[process.cwd()]})')" opencode
```

Для постоянного подключения или новой копии:

1. Из корня репозитория выполните `npm ci`, затем `npm run build:native`. Для сборки нужны Cargo и Xcode Command Line Tools. Проверка без записи: `./bin/rage doctor`. На macOS команда запускает Rust без Node. Если установить зависимости с `--ignore-scripts`, npm не скачает встроенный FFmpeg: понадобится установленный FFmpeg с AVFoundation или SoX для системного входа.
2. В `~/.config/opencode/cli.json` добавьте **абсолютный путь к каталогу** в существующий массив `plugins`. Если там уже есть опубликованная версия плагина, замените её локальной. Вместо `/absolute/path/rage` подставьте вывод `pwd` из корня репозитория:

   ```json
   {
      "plugins": ["/absolute/path/rage"]
   }
   ```

3. Запустите `opencode` из каталога своего проекта. На чистой установке уже выбрана `whisper-turbo`, автоотправка выключена. Модель не скачивается при запуске OpenCode. Если плагином уже пользовались, сохранённые настройки имеют приоритет.
4. Разрешите терминалу доступ к микрофону в системных настройках macOS. Если захватывается не тот вход, выберите микрофон в `/voice-settings`.

Откройте `/voice-settings` → **Микрофон**. В V2 список обновляется, пока меню открыто: подключите USB-микрофон, AirPods или iPhone, доступный в macOS через Continuity. Чтобы диктовать через телефон, выберите его по имени, включите запись на Mac и говорите в iPhone.

**Системный микрофон** берёт вход из **Системные настройки → Звук → Вход** для каждой новой записи. Если выбрать устройство по имени, плагин запомнит его. Подключение другого микрофона не переключает текущую запись. Если активный микрофон отключится, плагин распознает доступную часть записи, оставит текст в черновике и предложит выбрать вход для следующей записи. Черновик не отправляется автоматически.

Старые версии FFmpeg показывают только имя устройства. Если плагин не может различить два одноимённых микрофона, отключите второй перед записью.

**Проверка на своём iPhone.** Выключите автоотправку. Откройте список микрофонов на Mac и подключите iPhone: его имя должно появиться без повторного открытия списка. Выберите iPhone, нажмите `●` на Mac, произнесите короткую фразу и нажмите `■`. Фраза должна появиться в редактируемом черновике. Во второй записи отключите iPhone после нескольких слов: уже записанная речь должна остаться в черновике, а Rage должен предложить выбрать другой вход. Если запись не начинается, сначала проверьте, виден ли iPhone в **Звук → Вход** и выдан ли терминалу доступ в **Конфиденциальность и безопасность → Микрофон**.

При начале загрузки появится одно уведомление с названием модели и подсказкой, где смотреть прогресс. Под полем ввода появится `Загрузка модели 73%`. Если размер неизвестен, вместо процентов виден скачанный объём. При паузе сети подсказка остаётся на месте. Можно продолжать печатать: повторный выбор той же модели не запустит вторую загрузку. После проверки SHA256 появится `Диктовка готова` на три секунды или до начала записи. При сбое подсказка останется. Название модели, объём или причину ошибки можно посмотреть в `/voice-settings` → **Распознавание**.

## Что делают команды

В `/voice-settings` → **Распознавание** → **Модель** сначала показаны **Скачанные модели** из текущей папки загрузок. Выберите нужную, чтобы переключиться без повторной загрузки. Файлы, которым нужна проверка, показаны отдельно.

| Команда | Результат |
| --- | --- |
| `/voice` | Начинает и останавливает запись. По умолчанию вставляет текст в черновик. |
| `/voice-submit` | Отправляет сразу, если исходный чат всё ещё открыт. В остальных случаях оставляет текст в исходном поле ввода. |
| `/voice-stop` | Отменяет запись или распознавание. |
| `/voice-settings` | Выбор языка, модели, микрофона, клавиши, фильтра и автоотправки. |

Распознавание начинается **после** остановки. Whisper использует `whisper-cli`, модели Handy в формате GGUF (включая GigaAM для русского) используют `opencode-voice-transcribe`. Аудио обрабатывается локально. Отправленный текст становится обычным сообщением OpenCode; куда он уйдёт дальше, зависит от настроенного провайдера.

Для сравнения моделей запишите одну и ту же рабочую фразу с именами классов, путями и англоязычными терминами. Сравните ошибки в этих именах и время до результата. Выбор лучшей модели зависит от микрофона, железа и речи.
